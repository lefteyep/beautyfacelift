# Ihr Lead-Cockpit – Anleitung für Teresa

Das Lead-Cockpit ist eine kleine Übersicht aller Anfragen, die über die Website oder die Werbeseiten bei Ihnen eingehen. Sie sehen auf einen Blick, wer angefragt hat, wen Sie schon kontaktiert haben und wer einen Termin hat. Die Anfragen kommen weiterhin wie gewohnt per E-Mail; das Cockpit hilft, den Überblick zu behalten.

**Adresse:** https://beautyfacelift-zuerich.ch/admin/leads/ (am besten als Lesezeichen auf dem Handy und am Computer speichern)

## Anmelden mit dem Einmal-Code

1. Öffnen Sie die Adresse oben. Es erscheint eine Anmeldeseite.
2. Geben Sie Ihre E-Mail-Adresse ein (die Adresse, die wir für Sie freigeschaltet haben) und klicken Sie auf «Code senden».
3. Sie erhalten innerhalb von einer Minute eine E-Mail mit einem Code. Absender ist «Cloudflare» (noreply@notify.cloudflare.com). Falls die E-Mail nicht ankommt, bitte den Spam-Ordner prüfen.
4. Tippen Sie den Code ein. Danach sind Sie angemeldet und bleiben es rund zwei Wochen auf diesem Gerät. Danach bitten wir Sie einfach erneut um einen Code.

Es gibt kein Passwort. Wenn Sie «Abmelden» antippen, ist die Anmeldung sofort beendet.

## Die Liste

Nach dem Anmelden sehen Sie die Liste der Anfragen, die neueste zuoberst. Jede Zeile zeigt, woher die Anfrage kommt (Kontaktseite oder eine Werbeseite), den Status, wie lange die Anfrage her ist und welche Behandlung oder welches Thema gewünscht wird. Wenn eine Telefonnummer vorliegt, stehen gleich in der Zeile die Knöpfe «Anrufen» und «WhatsApp».

- Standardmässig zeigt die Liste «Offen»: alles, was noch neu, kontaktiert oder gebucht ist.
- Über die Reiter wechseln Sie zu einem einzelnen Status oder zu «Alle».
- Mit dem Suchfeld finden Sie eine Anfrage nach Name, E-Mail-Adresse oder Telefonnummer.

Tippen Sie auf eine Zeile, um die ganze Anfrage zu öffnen: Kontaktdaten, Nachricht, Wunschtermin und der bisherige Verlauf.

## Was die Status bedeuten

| Status | Bedeutung |
| --- | --- |
| Neu | Die Anfrage ist eingegangen, noch niemand hat geantwortet. |
| Kontaktiert | Sie haben sich gemeldet (Anruf, WhatsApp oder E-Mail). |
| Gebucht | Es gibt einen Termin. |
| Erschienen | Die Kundin oder der Kunde ist zum Termin gekommen. |
| Nicht erschienen | Termin vereinbart, aber nicht gekommen. Bitte eine kurze Notiz dazu. |
| Abgesagt | Die Kundin oder der Kunde hat abgesagt oder kein Interesse mehr. Bitte eine kurze Notiz dazu. |
| Nicht erreicht | Mehrere Versuche, keine Antwort. Bitte eine kurze Notiz dazu. |

## «Kontaktiert» markieren

Sobald Sie sich bei einer neuen Anfrage gemeldet haben, öffnen Sie die Anfrage und tippen auf **«Jetzt kontaktiert»**. Der Status wechselt von Neu auf Kontaktiert, und die Erinnerung (siehe unten) bleibt aus. Das geht auch direkt nach dem Anruf vom Handy aus.

## «Gebucht» markieren

Wenn ein Termin vereinbart ist, öffnen Sie die Anfrage und tragen unter **«Termin eintragen»** Datum und Uhrzeit ein. Das Häkchen «Status auf Gebucht setzen» ist bereits gesetzt; mit «Termin eintragen» ist die Anfrage gebucht. Der Termin selbst wird weiterhin wie gewohnt in Ihrem Buchungssystem geführt; das Cockpit merkt sich nur, dass es ihn gibt.

Nach dem Termin können Sie unter «Status» festhalten, ob die Person erschienen ist. Unter «Notizen» können Sie sich Dinge merken, die nur Sie und die Agentur sehen.

## Die Erinnerung per E-Mail

Wenn eine Anfrage nach einer Stunde noch auf «Neu» steht, erhalten Sie während der Öffnungszeiten eine E-Mail mit dem Betreff «Noch offen: Anfrage von …». Sie enthält die wichtigsten Angaben und die Knöpfe «Anrufen», «WhatsApp» und «Im Lead-Cockpit öffnen». Jede Anfrage wird nur einmal erinnert. Anfragen, die abends oder am Sonntag eingehen, werden am nächsten Öffnungstag erinnert.

Auch die normale Anfrage-E-Mail enthält den Knopf «Im Lead-Cockpit öffnen», der direkt zur passenden Anfrage führt.

## Testanfragen und Spam

Eine Testanfrage oder offensichtlichen Spam müssen Sie nicht löschen: Öffnen Sie die Anfrage und wählen Sie unten «Ausschliessen». Der Eintrag verschwindet aus den Listen, nur unter «Alle» bleibt er sichtbar.

## Wenn eine Kundin ihre Daten gelöscht haben möchte

Das Cockpit hat bewusst keinen Löschknopf. Melden Sie den Wunsch bitte der Agentur; wir löschen die Anfrage dann für Sie und bestätigen es Ihnen. Anfragen werden ohnehin spätestens 24 Monate nach dem letzten Kontakt gelöscht.

## Bei Fragen

Wenn etwas nicht funktioniert, Sie keinen Code erhalten oder eine Anfrage fehlt, melden Sie sich bei Ihrer Agentur mediapaulo (mediapaulo@gmail.com). Wir sehen dieselbe Liste und helfen gerne weiter.
