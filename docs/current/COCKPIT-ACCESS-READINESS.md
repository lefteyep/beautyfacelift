[`worker/leads/access.ts`](../../worker/leads/access.ts) verifies RS256 signatures using the configured team's keys, issuer, application audience, expiry/not-before and an exact email allow-list. It does not query session revocation: immediate logout/revocation depends on Access actually covering the request path. Test that coverage and replay behaviour before rollout; local signature validation alone cannot establish it.
