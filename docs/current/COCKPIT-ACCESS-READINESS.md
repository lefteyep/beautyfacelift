## Existing protection and recommendation

[`worker/leads/access.ts`](../../worker/leads/access.ts) verifies RS256 signatures using the configured team's keys, issuer, application audience, expiry/not-before and an exact email allow-list. Missing configuration denies access. The email identity header alone is rejected; development identity is limited to loopback and excluded in production. Key caching/backoff is deliberate: a required key fetch that fails denies access; already cached valid keys can still verify tokens. [`worker/index.ts`](../../worker/index.ts) guards `/admin/` including encoded/case/repeated-slash variants before assets; cockpit responses are `no-store`. `wrangler.jsonc` has `run_worker_first: true`, `workers_dev: false`, production mode and empty team/AUD values. Keep these safeguards.

No demonstrated code security blocker was found. Cloudflare also requires origin-side JWT validation when no Tunnel performs it; the current verifier serves that purpose. It does not query session revocation: immediate logout/revocation depends on Access actually covering the request path. Test that coverage and replay behaviour before rollout; local signature validation alone cannot establish it. [Application tokens](https://developers.cloudflare.com/cloudflare-one/access-controls/applications/http-apps/authorization-cookie/application-token/)

| Option | Who owns login maintenance |
| --- | --- |
| Access email PIN + existing guard — recommended | Cloudflare issues/checks PINs and manages login sessions. Agency owns exact policies, mailbox security, access removal, monitoring and Worker configuration/verifier maintenance. |
| Custom code delivered through Resend | Agency additionally implements secure issuance/storage, expiry, one-use atomic consumption, replay/brute-force/send-abuse limits, account-enumeration handling, secure cookies, session rotation/revocation/logout, CSRF integration, recovery, deliverability and regression tests. Resend delivers mail; this would be a new authentication system. No implementation or cost estimate is approved here. |
