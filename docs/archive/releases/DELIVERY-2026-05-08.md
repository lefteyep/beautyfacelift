# Delivery Update - 2026-05-08

This note documents the homepage and treatment-page polish released from the active `astro-v2` project on 2026-05-08.

## Scope completed

### 1. Homepage mobile hero cleanup

- Removed the mobile-only quick booking block between the image collage and H1.
- Removed the mobile proof text `Teresa persönlich · Bahnhofstrasse 94` from the above-the-fold hero because it did not fit the context.
- Hid the small uppercase hero label on mobile to reduce vertical clutter.
- Reduced the mobile hero image collage from the previous wide mobile scale to a 340px cap so the copy and CTAs appear sooner.
- Added matching critical CSS in `Base.astro` so the first paint uses the same mobile hero sizing before the full stylesheet loads.

### 2. Homepage hero copy update

- Replaced the old brand-only H1 with:
  - `Ihre persönliche Schönheitsadresse an der Bahnhofstrasse Zürich`
- Replaced the keyword-heavy hero paragraph with:
  - `Hochwertige kosmetisch-ästhetische Behandlungen – persönlich abgestimmt von Teresa Stimac, Kosmetikerin mit über 20 Jahren Erfahrung.`
- Scoped the homepage hero display type scale so the longer H1 fits on mobile and desktop without clipping.

### 3. Treatment CTA copy and WhatsApp consistency

- Updated shared treatment action-bar copy from generic direct-booking language to treatment-planning language.
- Replaced hard-coded WhatsApp URLs with the shared `CONTACT_WHATSAPP_URL` constant.
- Standardized secondary CTA labels to `Frage per WhatsApp`.
- Updated Exosome Therapie CTAs from consultation-first wording to clearer appointment-planning wording.

### 4. Treatment page layout refinements

- Added shared `.treatment-copy-block` and `.treatment-callout` styles for centered explanatory treatment copy.
- Applied those styles to the Exosome Therapie expectations block and the treatment comparison callouts.
- Refined `.process-grid` and `.process-step` so process cards use a more flexible grid, tighter spacing, and better mobile stacking.

### 5. Favicons and app icons

- Added a shared `HeadIcons.astro` component for favicon, Apple touch icon, manifest, and tile color tags.
- Reused the shared icon head component in both `Base.astro` and `LandingPage.astro`.
- Replaced the old SVG favicon reference with ICO and PNG icon assets.
- Updated `manifest.json` to reference the generated Android PNG icons.

### 6. Worker static asset deploy hardening

- Updated `npm run cf:deploy` to pass `--assets=./dist` explicitly to Wrangler.
- Added `--old-asset-ttl=0` to expire replaced static assets immediately during deploy.
- Added Worker-side HEAD handling for static asset responses by fetching the corresponding asset as GET and returning headers without a body.
- Added a document asset release key for HTML routes to avoid stale cached document responses after the live update.

### 7. CTA and navigation visual hotfix

- Set the global gold `.pill-btn` text color to `#ffffff` so primary CTA labels render white instead of black.
- Kept the gold CTA hover state explicitly white with `#ffffff`.
- Updated desktop `.nav-links` from `font-weight: 400` to `font-weight: 600`.
